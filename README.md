# odin_rock-paper-scissors
Project ODIN exercise project, creating a rock paper scissors game

This game is played via the prompts and alerts, but can also be tracked in the console.

This simple rock paper scissors game prompt the user to select rock, paper or scissors, while using uses a random integer generator to decide the option the computer will take.

The game has 5 rounds and then will declare the winner.


Learnings:
Functions, parameters and Arguments, nested functions,  for loops,
global and local scope functions, as well as planning, psuedocoding and debugging.
